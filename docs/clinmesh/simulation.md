# 仿真业务边界：同一病例，不同轮次的诊疗

仿真的业务目标是让不同岗位在相同病例起点上作决定，比较实际做了什么，而不是把预设答案填进病历。**准备病例、开始就诊、完成诊疗是三个不同的事件。** 本册仅依据业务合同、实现与测试断言，不使用任何具体病例、报告正文或影像内容。

## 一、五类证据，不同的读者

| 概念 | 谁使用、证明什么 | 不证明什么 |
| --- | --- | --- |
| 病例来源与不可变修订（Synthetic Patient Profile / Case Revision） | 仿真管理员准备生成或预先编写的合成病例；来源修订确定起点。一次就诊绑定其所用修订 | 来源里的诊断、操作不是本院本次的诊断、手术或账目 |
| 可见来源病史（Visible Source History） | 获授权的临床岗位读取来源就诊之前的既往信息；可作为问诊和判断的依据 | 既往记录不是当前就诊新作出的结论，不能冒充本次签署的报告 |
| 病例真值（Case Truth） | 仿真侧保存待探索的本次来源事实；本工作区管理员可通过专门的核对入口查看。临床岗位只能经授权问诊、申请及结果逐步观察 | 不随普通病例详情、临床工具或患者对话直接公开；管理员核对也不等于临床确认 |
| 患者角色稿（Patient Persona Revision） | 界定模拟患者能讲出的主诉、记忆与已知病史。开始前须选用成功修订；修改产生新修订，已开始的绑定不随之改写 | 患者的叙述不是客观检查值；它也不是给医生发放的答案 |
| 检查结果快照（Investigation Result Snapshot）与正式报告 | 仿真侧冻结一次成功解析的结果输入与输出；医院侧在该轮次真正执行后才有自己的申请、报告与签发来源 | 有快照不等于后续轮次已经开单、付款、送检、签发或确认已阅 |

工作区是不同使用方之间的隔离边界；轮次（Epoch）是同一工作区不同运行数据世代之间的隔离边界。来源修订、角色稿与成功结果快照可在同一工作区跨轮保留；本院患者、就诊、处方、费用、未完成动作等有具体轮次。场景运行（Scenario Run）描述一次仿真是否活动或完成，不等于任一位患者的临床完诊。

## 二、从准备到重新开始

1. **管理员备料。** 生成或准备来源、建立病例及选用角色稿。预先编写的病例包可选用随包模板，不必调用模型。此时没有本院已完成的检查、医嘱、手术或费用。公开授权、去标识的影像或切片仅是清单限定的素材例外；不引入素材来源患者的身份、诊疗过程或账单。
2. **登记员开始就诊。** 以当前病例、已选角色稿修订和预期轮次办理；普通开始只消费一次。门诊建立本院患者、挂号、就诊与队列等；直接入院建立住院就诊、账户等入院事实，不虚构一段门诊流程。网络应答不明时恢复原办理回执，不以「现在已开始」推断是哪一次操作成功。
3. **运行中揭示结果。** 仿真执行方按冻结服务、来源与当前阶段解析，首诊、同次复测、住院及出院后随访可选择不同分阶段事实；只在输入相符时复用成功快照。无相容证据且无适用生成规则时失败，而不是自动填写正常。负责医生获得的是该轮已签发的临床结果，不获得匹配底账。
4. **管理员重置。** 默认保留患者库，用同一不可变病例修订及所选角色稿在新轮次重新建立起点，可复用输入匹配的结果快照；不重跑病例生成，也不把上一轮的医嘱、给药和支付搬入新一轮。可选择同时清空当前患者库：归档并退役关联病例，不重放，不等于删除旧轮次与审计。
5. **旧轮次收口。** 关闭旧轮次，终止未完成的旧运行派发；已完成的场景保留原完成状态。旧岗位预览、写回执和业务引用不能跨入新轮，迟到的旧执行结果不得生成新轮报告。这里的「重放」不是按历史命令逐步恢复现场；没有通用检查点恢复或自动评分类能力。

## 三、时间、审计与验收反例

**虚拟时钟**回答「在这次演练里何时发生」；**真实接收时间**回答「系统何时收到」。管理员可按预期当前时间显式推进，只能向前、单次最多 366 天；同一时刻重复推进不新记费用。跨业务时点可触发床日计费和长期医嘱排程，不会替护士确认给药。身份有效期及审计接收时间不取虚拟时钟。

行动轨迹（Action Trace）按场景关联业务命令尝试、结果、产生的事实及其版本，使用虚拟时间；它不记录每次普通浏览，也不保存模型思考过程。审计事件（Audit Event）保留真实接收时间；临床来源记录（Provenance）说明某个正式资源从何而来。三者回答不同问题，不互相替代。

| 复核问题 | 预期辨别 |
| --- | --- |
| 已备好一个带检查来源的病例，但登记员尚未开始；医生能查到一份本院报告吗？ | 不能。准备只使病例就绪，不产生本院诊疗事实。 |
| 同一修订做过首诊检测，复诊时同编码就能照抄结果吗？ | 不能仅按编码复用。区分就诊阶段与输入；即使快照可复用，也必须走本轮正式执行。 |
| 护士推进演练时间，或推进者想以时间流逝证明已给药，可以吗？ | 推进是管理员动作；时钟能生成到时任务，不能生成护士实际给药。 |
| 重置前排队的检查迟到，能否把报告写到新住院？ | 不能。执行提交重新核对活动轮次；旧行为仅保留原轮次的轨迹和审计。 |

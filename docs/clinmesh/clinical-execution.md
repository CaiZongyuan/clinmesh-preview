# 临床执行：从医生意图到患者实际接受的诊疗

ClinMesh 中，医生签发请求只证明「决定做什么」。药师要对发出的批次和数量负责，护士要对实际执行负责，医技报告须另行签发，医生还需确认已阅。收费有自己的发生条件，不能反推出患者已经接受了治疗。以下只描述合成医院实际可核验的业务，不是现实医院操作规程或诊疗建议。

## 一、谁对哪项事实负责

| 业务对象 | 归属、关系与可观察结果 | 不能替代 |
| --- | --- | --- |
| 院内可开立项目 | 本院为具体药品或服务确定启用范围、版本、执行所需单位及规则；签发时核对当前配置、保存当时的定义 | 参考目录中检索到某项，不代表本院已开展、可收费或适合此患者 |
| 门诊用药结论 | 对一次门诊，责任医生签发有效处方或明确记录「无需用药」；院内处方以处方号归组，每行一个药品请求 | 草稿、空处方和已撤回处方都不是有效用药结论 |
| 住院医嘱与执行单 | 一次住院可有多条长期或临时医嘱；同一条医嘱可对应多个执行时点，各次执行分开核对 | 医嘱已校对、执行时点已到，不代表药品已发出或给入 |
| 药品发放、给药与库存移动 | 药师对本次发放选定的产品、数量、批次负责；护士另行确认给药。药房批次由门诊与住院共享 | 库存扣减不是患者用药史；停嘱不是退药、退款或冲账 |
| 医技申请、报告修订与已阅 | 申请绑定患者、就诊、服务及签发责任；报告由执行方签发，确认记录指向医生实际核对的报告版本 | 打开报告不是已阅，旧版已阅不能证明新版已阅 |
| 手术申请与实施 | 同次住院可有多项计划；实际手术引用具体申请，分开保存计划术式与实际术式、实施时点和责任岗位 | 到计划时间不代表做过；预估或预留的材料不是实际使用 |

## 二、用药：门诊处方与住院医嘱是两条链

### 门诊：先确认用药结论，再分流到药房或院外〔E1〕

1. **准备。** 责任医生核对本次已确认诊断、过敏及可用目录，编辑 1–8 条药品、剂量、频次、疗程及数量。只保存草稿不产生正式药品请求。专病组套和建议也只能产生待核对项。
2. **签发。** 在最终确认时重新校验诊断、组合、用量、过敏和草稿版本。整张处方只允许一个目录来源；有一条不合格，整单不签发，保留可纠正的草稿。已有有效处方与「无需用药」不可并存。
3. **本院药房分支。** 签发形成正式处方、逐药品请求及本院应收。完诊后办理药费收款；支付完成再交药房审核和按批调剂。部分发药只形成实际发出的数量，剩余数量继续待发；按行保留发放与原药品请求的对应关系。门诊发药不产生病区护士的给药记录。
4. **外延处方分支。** 纯国家参考目录处方同样有正式处方号和药品请求，能满足完诊用药条件；不创建本院零元费用，也不进入院内收费或药房队列。模型不推断患者已在院外购药。
5. **撤回。** 原责任医生可撤回尚未发生任何调剂且财务条件允许的处方。未知或部分收款、有效医保分配等须先处置；已发出任意数量即不能走处方撤回。撤回保留原处方并取消请求；对已收款处方不隐式退款。其后才可改记「无需用药」。

### 住院：按执行时点分担责任〔E2〕

| 时点 | 负责岗位与前提 | 成功后新增或改变的事实 |
| --- | --- | --- |
| 开立 | 本次住院当前责任范围内的住院医生；验证药事规则、院内产品与版本、每次制剂数量及频次。术后医嘱另须引用本次已完成的手术 | 产生 `signed` 医嘱；药物为用药请求，健康教育为服务请求。无发药、给药或正式费用 |
| 校对及排程 | 当前病区护士校对 `signed` 医嘱；长期医嘱按本院班次排程、首日不补过去的时点，临时医嘱只执行一次 | 进入 `verified`，生成待办执行单；跨日展开后续长期任务，但不自动完成。`ONCE` 不用于长期医嘱 |
| 按需办理 | `PRN` 不因校对或跨日自动展开。护士须按在效医嘱填写本次理由，受当日有效次数及总量约束 | 新增一次待执行任务，不生成给药事实；同日停嘱重开不能用来重置同药上限 |
| 实际发药 | 药师核对可发执行单、医嘱状态和有效库存批次；住院不要求先缴单项药费 | 执行单转 `dispensed`；本次实际发放、批次扣减和费用一并记录。库存竞争或写入失败不留部分扣减 |
| 实际给药或服务 | 到执行时点、已经发药并实际给入后，由护士记录给药；健康教育是独立服务，须实际开展 | 药物有一次实际给药事实；不再重复计药费。教育任务完成时才计服务费，不能用此通用动作完成检验或影像 |
| 停嘱 | 医生可对 `signed` 或 `verified` 医嘱注明理由申请停用；护士核停 | `stop-requested → stopped`。申请即冻结新任务、发药和给药；核停取消待执行或已发待给任务，保留此前的库存、发放、给药和已记费用 |

药师看到执行所需药嘱、相关批次及有效过敏风险；收费员看到费用及净额，不据此获得诊断、医嘱全文或给药明细。集中处理多项时，每项仍有自己的前提、正式结果与回执；后项冲突不抹掉前项已完成的动作。它与门诊**整张处方原子签发**不同。

### 临床安全与建议权限〔E3〕

当前四类版本化专病组套覆盖胸痛快速检查、冠心病入院基础评估、围术期水化和冠心病介入二级预防。它们使用当前可见且可核实的过敏、肾功能和生命体征筛选候选；缺项须显示待核实原因，禁忌项不当作可开立项。使用组套本身不会产生应收、正式申请或执行计划。

签发时要区分三种情况：**资料缺失**不是已证明异常，也不是正常；**安全红线**不能靠填写理由绕过；**路径或指南偏离**可由负责医生补齐依据，或在允许的警示上选择受控原因、留下医学依据并随原决定保留。辅助建议不拥有签发权。这里建模的是系统对责任和依据的约束，不是对真实患者的用药规则。

## 三、医技：申请、执行、签发、已阅各有归属

**共同主链〔E4〕：** 医生选择本院项目并签发 → 满足该次就诊的放行条件 → 医技受理并执行 → 报告签发 → 医生确认指定版本已阅。门诊检查新申请通常按原申请生成唯一应收；自付及医保等确定资金收齐后放行，未知支付不能当作已收款，升级前未计费历史有单独兼容策略。住院支持的检验、放射和功能检查则由病区护士显式送检，报告执行完成才计一次费；不借用门诊预付费条件。

| 类型 | 在本院发生什么 | 资料不完备时怎样处理 |
| --- | --- | --- |
| 检验〔E4〕 | 医生选可开立的院内根项目，冻结服务、报告定义；组合的子指标是结果，不自动成为独立可开立项目。受控检验执行方签发结构化观测和报告；住院检验报告、标本属于本次住院 | 优先使用精确合成来源，只有配置且适用的项目才可按受限成人参考规则生成。缺项或不兼容不能当作正常；医生看到的院内目录不暴露病例隐藏结果 |
| 放射〔E5〕 | 当前为胸片、胸部 CT 平扫；签发报告的同时形成本次本院检查事实，引用患者、就诊和申请。素材标识不是患者检查号 | 医院未开展不允许签发；无可用结果可进入生成失败。已发布的文字报告可读而像素不可读时，仍不能确认已阅；更正只用同一素材另一个已核对报告修订 |
| 功能检查〔E6〕 | 十二导联心电图、经胸超声心动图。结果是方法、文字所见、印象和结构化指标，无波形、影像检查实例或像素前提 | 部分精确结果不能与推测正常值拼成完整报告。正常基线仅限满足合成来源、年龄及证据无冲突等条件的病例；不满足则失败而非生成正常报告 |
| 门诊病理会诊〔E7〕 | 为患者**已有、医生可见的既往乳腺手术**选择来源；本院病理执行方接收携来 H&E 切片，签发会诊报告，绑定来源手术与本次申请 | 医院开展此项目不等于患者有可选来源。来源不再可选则不签发；没有兼容切片不造报告。非本院新活检、冰冻、细胞学或通用住院病理 |

**取消、重试、更正。** 门诊原开具医生可取消尚未受理的已开立申请或符合条件的失败申请；取消与受理争用时只有一个结果，迟到执行不能复活已撤销申请。有可恢复错误才按该类型重试，不借新申请隐藏原失败。报告更正保留原版本与旧确认，最新有效版本须再确认；打开或批量浏览不代替明确已阅。未取消请求尚未完成或最新报告未阅时，不满足相应临床收尾条件。住院在途报告跟随原住院：转科改变当前责任，不改其所属就诊、不重收执行费。〔E4–E7〕

## 四、住院手术：计划、术前确认、实施和耗材〔E8〕

| 业务动作 | 产生的事实与约束 |
| --- | --- |
| 发起计划 | 当前住院医生填写计划术式、计划时间及所需依据，形成 `requested` 手术申请。多项计划分别标识；不产生实际操作、术式费或耗材费 |
| 准备 | 病区护士记录术前核对；住院医生记录「知情同意书已签署」的确认。两项分别留人和时间，全部具备才 `ready`。这不是电子签署系统 |
| 预计及预留 | 术前耗材预计是数量与费用推演；正式确认时冻结原计划，不能用术后余额反推术前预计。预留是有归属的预计用量记录，不是实物库存锁定、消费或收费 |
| 实际实施 | 就绪后，可一次性登记实际术式和用材并完成，也可先开始、逐笔登记术中材料、最后确认完成。逐笔实际用材即记录相应费用，但不提前完术；一次性实施若后项材料不合格，整台回滚。术式改变、偏离已确认清单等须说明依据 |
| 结束或取消 | 尚未实际开始的 `requested/ready` 可取消，释放该申请绑定的活动预留，不制造手术事实。未收口申请阻止转科交接和出院。病案首页依据本次**实际已完成手术**，术后医嘱也只能关联本次已完成实施身份，不得引用计划或既往外院操作 |
| 术后补记及纠错 | 可追加漏记的实际使用；更正保留原记录，追加原费用冲正及相应替代记录，须能追溯到同台手术与原用材。已用量、正式收费净额及原确认的预计量分别计算，不相互覆盖 |

**边界。** 这是有明确院内术式、耗材和合成费率的住院手术闭环，不是完整手术室排班或麻醉系统。参考耗材即使有报价，缺计价单位就不能登记使用并收费。耗材预计/预留与药品批次库存是两个领域；不要据此推断本院有耗材采购、仓配或批号供应链。

## 五、业务验收问题（可用合成场景复核）

| 给定／操作 | 应观察到 | 不应观察到 | 证据 |
| --- | --- | --- | --- |
| 同一次门诊选择一条院内药和一条外延药，尝试签发 | 拒绝整单，可回到草稿纠正 | 半张处方、费用或药房任务 | E1 |
| 住院执行单已发药，尚未到给药时点，医生申请停嘱、护士核停 | 取消待给执行；原发放、扣减及药费可追溯 | 自动给药、库存自动返还、药费消失 | E2 |
| 对尚未收齐费用的门诊检查尝试启动；对已签发但未送检的住院申请推进时间 | 原申请继续等待本场景的放行条件 | 凭开单或时间流逝生成报告 | E4 |
| 胸片文字报告已签发但像素不可读；或原已阅报告发生更正 | 前者可读文字但不能确认；后者保留旧版并要求重新确认 | 显示最新版已阅，或据旧确认通过完诊门禁 | E4、E5 |
| 手术已完成术前护士核对，但医生尚未确认同意；之后补齐并合法实施 | 前次拒绝，后次形成实际手术、实际用量及对应费用 | 前次留下一部分费用；把计划量当实际量 | E8 |
